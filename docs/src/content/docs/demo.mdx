Try Plim right here. The editor below is the
[`examples/notion-clone`](https://github.com/darylcecile/plim/tree/main/examples/notion-clone)
app - a small Notion-style client built on `@plim/react` - deployed to Vercel and embedded
live. Type `/` for the slash menu, select text for the floating toolbar, and drag the block
handle in the gutter to reorder.
