## What is Plim?

Plim is a Notion-inspired block editor built as a TypeScript monorepo. It ships a
framework-agnostic core, a DOM view layer, a Markdown parser/serializer, and React
bindings - all small, composable, and designed to be embedded in your own product.

:::note[Status]
Pre-1.0 (`0.0.x`). The public API is mostly stable but may shift before `1.0`.
:::

## Packages

| Package | Description |
| --- | --- |
| [`@plim/core`](/api/core/) | Schema, document model, transactions, validation rules, action/extension/trigger system, history, and the built-in block & mark descriptors. Runtime-agnostic - no DOM. |
| [`@plim/ledger`](/api/ledger/) | Record, replay, merge, diff, and rebase transactions plus conflict resolution - the bring-your-own sync / CRDT layer. Runtime-agnostic. |
| [`@plim/transports`](/api/transports/) | Tiny generic duplex-channel primitives: in-memory loopback + broadcast bus, `BroadcastChannelTransport`, reconnecting `WebSocketTransport`, and `mapTransport` codecs. Zero-dep. |
| [`@plim/collaboration`](/api/collaboration/) | Real-time multi-peer editing on top of the ledger, presence/awareness, and version vectors - plus comments & threaded replies. |
| [`@plim/markdown`](/api/markdown/) | Parse Markdown into a Plim document and serialize back. |
| [`@plim/editor`](/api/editor/) | The view layer. Mounts a Plim document into a `contenteditable`, owns the floating toolbar, block-handle gutter, clipboard, drag-and-drop, and the keyboard pipeline. Ships its own stylesheet. |
| [`@plim/react`](/api/react/) | React bindings: `<PlimEditor>`, `useEditorHandle()`, slash-command and mention extensions, and a bridge for defining blocks with `toComponent`. |
| [`@plim/html`](/api/html/) | Headless, SSR-safe serializer: render a document model to an HTML string with overridable renderers and escaped-by-default output. Optional. |
| [`@plim/storage`](/api/storage/) | Durable persistence primitives: pluggable `StorageAdapter`s (memory, `localStorage`, IndexedDB, transport) plus debounced snapshot autosave. Optional. |
| [`@plim/test-utils`](/api/test-utils/) | Runner-agnostic testing helpers: fluent document/mark builders, a headless `createTestEditor`, `applyTx`, and inspectors/assertions. |
