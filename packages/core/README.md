# @plim/core

Schema, transactions, validation, and built-in block/mark descriptors for the [Plim](https://github.com/darylcecile/plim) block editor. This package is runtime-agnostic — it has no DOM dependencies and is consumed by `@plim/editor` and `@plim/react`.

## Install

```sh
pnpm add @plim/core
```

## Documentation

See the [Plim repository](https://github.com/darylcecile/plim) for the full API reference and examples.
