# @plim/editor

The view layer for the [Plim](https://github.com/darylcecile/plim) block editor. Mounts a Plim document into a `contenteditable`, with paste handling, selection, drag-and-drop, the floating toolbar, and the block-handle gutter.

## Install

```sh
pnpm add @plim/editor @plim/core
```

Import the bundled stylesheet once at your app's entry point:

```ts
import "@plim/editor/styles.css";
```

## Documentation

See the [Plim repository](https://github.com/darylcecile/plim) for the full API reference and examples.
