# @plim/ledger

Record, replay, merge, diff, and rebase transactions for the [Plim](https://github.com/darylcecile/plim) block editor. The runtime-agnostic, bring-your-own sync / CRDT layer built on `TransactionLedger` and `LedgerRecord`, with conservative conflict detection and OT rebase.

## Install

```sh
pnpm add @plim/ledger @plim/core
```

## Documentation

See the [Plim repository](https://github.com/darylcecile/plim) for the full API reference and examples.
