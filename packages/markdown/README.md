# @plim/markdown

Markdown parser and serializer for [Plim](https://github.com/darylcecile/plim) documents. Converts Markdown into Plim's block tree and back.

## Install

```sh
pnpm add @plim/markdown
```

## Documentation

See the [Plim repository](https://github.com/darylcecile/plim) for the full API reference and examples.
