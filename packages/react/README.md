# @plim/react

React bindings for the [Plim](https://github.com/darylcecile/plim) block editor. Define block descriptors with React components and host them inside a Plim editor.

## Install

```sh
pnpm add @plim/react @plim/editor @plim/core react react-dom
```

## Documentation

See the [Plim repository](https://github.com/darylcecile/plim) for the full API reference and examples.
